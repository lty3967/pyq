# php版朋友圈开源源码
一个全新朋友圈程序PHP源码项目
功能：
1.可跟朋友圈一样发布文字，图片，视频等内容；
2.可互动式点赞，评论
3.用户管理：用户可注册账号，发布自己的朋友圈内容，也可以管理别人评论的内容以及回复；
4.后台管理：管理员可发布自己的朋友圈内容，管理所有的朋友圈内容，设置分类，管理用户和评论，设置评论违禁词以及IP黑名单，设置管理员信息，发信功能以及站点设置；
5.更多功能持续更新中，bug或者建议可反馈到QQ825703967；
